# Student academic progress

Keep one student account and admission number throughout the student's time at the school.
The progress history follows that student, not their current class.

## At admission

1. Create the student and assign the entry class, such as Form 1A or Grade 1A.
2. Set the admission date and retain the admission number in future years.
3. Create academic terms with the correct year and start/end dates.

## Each term

1. Record scores against the correct class, subject and term.
2. Generate the term results using the existing result-generation process.
3. Saved results automatically appear in academic progress; separate progress logs are not required.

## Moving to the next class

1. Create or select the destination class, such as Form 2A or Grade 2A.
2. In the administrator's student record, change the assigned class and save.
3. Keep the same student record. Do not create a new account or rename the old class as a way of promoting students.
4. Record new scores against the new class and the new academic year's terms.

Class levels 1–10 are supported. Name secondary classes Form 1–4 and primary classes Grade 1–10 as appropriate for this school's structure. Advancement is an administrator decision; viewing progress does not automatically promote anyone.

## Viewing progress

- Students: My Results → View progress across all years.
- Administrators: Results → select class and term → View progress beside a student.
- Teachers: use the existing progress control for a student they teach.

The view includes a chronological term-average chart, year summaries, and a complete term table with class, grade, position and change in percentage points. Year averages are the arithmetic mean of recorded term-result averages, not a weighted examination score. Missing results are not treated as zero, and fewer than three recorded terms is an incomplete year.

Changing a student's current class does not remove earlier results. Saved results retain their recorded class name and level, and classes or terms with saved results cannot be deleted. Mark old classes inactive instead.

On upgrade, existing results are assigned the class name and level currently held by their linked class. The system cannot reconstruct changes made before this history feature existed. Earlier years must have their actual scores/results entered before they can be displayed; no historical marks are invented.
